# levo-calculator
Lean Base Mass L-T4 starting dose

What the calculator includes:

Section 1 — Demographics & Anthropometrics

Metric/imperial toggle (kg/cm or lb/in)
Sex toggle (affects James formula coefficients)
Age input (used for age-stratified SPINA-GD interpretation)
Height + weight → BMI and LBM update live as you type

Section 2 — Lab Values

TSH, FT4, FT3, eGFR, Anti-TPO, HbA1c
All optional — calculator works with height/weight alone
FT3 + FT4 required for SPINA-GD; TSH + FT4 for SPINA-GT

Section 3 — GLP-1 Recalculation

Enter new weight after weight loss
% lost and new LBM auto-calculated
Dual mechanism warning (weight loss + absorption effect)

Results panels

Dose hero: LBM dose (recommended) vs traditional dose side by side, traditional dose with strikethrough

4 stat tiles: BMI, LBM, % overestimate, TSH status — colour-coded green/amber/red

Animated overestimate bar (0–200% scale)

Contextual alerts: dosing danger zone, female LBM plateau, TSH suppression, CKD, anti-TPO

SPINA-GD/GT cards with bars, colour-coded interpretation, localisation logic (GT normal + GD low = conversion defect)

Age ≥60 deiodinase warning from NHANES regression

GLP-1 before/after comparison with 10% milestone flag

Clinical summary with one-click copy to clipboard
